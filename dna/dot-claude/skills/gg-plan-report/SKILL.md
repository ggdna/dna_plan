# /gg-plan-report

Read [report-guide.md](../../../doc/guides/report-guide.md) and work by
it.

## Important

- Ask for the person first; default: everyone in `team/people.md` of the
  current quarter
- Without `team/people.md` and `team/roles.md`, set up the team with the
  user first
- In a new quarter, start its folder first, see the PM repo guide
- Show the proposed points before writing; write only confirmed ones
- Never untick, delete or rewrite a point
- Keep the German copy in step, ticks included, if the repo has one
